01　建议的审查路线

打开创作台，先选图文或视频，再选目标成品。用本地商品图或案例填入需求、平台和比例，进入对应插件核对。本地演练的费用为 0 积分。也可从工具库搜索一个具体编辑动作，或在素材库继续使用本次会话添加的商品图。

参考已登录的飞象灵感页，重点研究其图文／视频切换、成品类型、素材与提示输入、参数及提交前费用提示。当前方案以侧栏导航、集中创作面板和插件工作流实现这些交互。

当前原型覆盖页面切换、五个插件的双模式草稿、授权拦截、任务结果与重试、插件启停和语音配置。工作区总览可审查项目归档、成员邀请和角色、资料检索、项目提醒、消息、自检与代理结算。本地编辑器支持图片缩放裁切预览、分镜清单导出、回复草稿、逐项商品确认与文案版本。生成物、授权和平台回执均为本地演练。PSD 编辑、真实聊天接管、支付、安装升级及实际发布按下文设计，进入开发后联调。

区域页面与用户路径权限与恢复行为
公开官网首页 → 产品能力与适用场景 → Windows 下载与二维码，或企业／个人／代理注册登录。下载处展示版本、系统要求和安装说明。公开访问；登录后的目标路由由服务端身份与授权决定。安装失败仍可从网页查阅说明。
账户与首次进入注册、登录、邀请接受、企业选择、新手引导。首次启动进入创作台；从侧栏中的企业入口进入角色工作区。邀请失效可重新申请；成员被移除或会话过期时停止请求，显式提示重新登录或切换工作区。
项目工作区项目列表 → 项目概览 → 插件工作室 → 素材、历史任务与结果。顶部始终显示当前企业和项目。成员只见分配项目；归档项目以只读方式打开。切换项目先保存当前草稿，再按新范围取数。
共享资料企业／个人知识、文档分类、记忆、专家团、技能定义、检索与挂载。结果给出来源库，允许回到原文。库和成员权限控制搜索候选、引用和下载。个人记忆与企业记忆分别标明作用域。
企业与经营管理员邀请成员、角色、套餐、积分包、额度与双向流水；代理入口提供两级关系、比例及月度结算导出。企业成员看到本人额度；个人看到个人余额；代理看到允许范围的订单与结算。配置比例权限按后端授权决定。
系统工作区任务记录、通知中心、插件管理、设置、诊断与安全模式。完成和失败通知可回到对应任务。系统通知按类型和免打扰生效，站内仍可查；全部可选插件停用后仍保留恢复入口。

03　桌面布局与交互语言

桌面侧栏分为创作台、工具库、素材库和插件管理。首屏使用原创折光纤维背景，焦点集中于商品素材和提示输入区域。图文与视频共用创作面板，平台、比例与参考风格集中在提交区。试用示例会载入素材和提示词。下方提供六个常用工具和品类筛选案例。进入编辑器后由预览区、参数区和任务记录组成。

组件操作约定尺寸与无障碍
导航与工具栏宿主按扩展注册表展示可用入口。当前位置有文字、形状与颜色反馈。主动作仅一个，次操作为浅底按钮。中等窗口收窄侧栏。小屏导航转为顶栏，预览与参数上下排列，参数和主操作可换行。详细表格允许独立横向滚动。
预览与检查器预览负责“看结果”，右栏按素材、参数、确认推进。参数错误贴近字段；长任务在任务记录中观察，可离开页面。正文 14–16 px，参数标签不小于 12 px；Windows 中文优先使用微软雅黑，缩放至 125% 和 150% 复测。
颜色与反馈采用冰蓝玻璃、细亮边与青紫极光。工作台浮板可拖动，松手约 340 毫秒回弹；模式滑块约 420 毫秒落位。玻璃主题在导航、表单、数据表、编辑器和弹窗复用同一套材质。顶栏还能切换暖白纸笺、雨后青玉和曜石鎏金，主题选择不影响编辑草稿。正文、商品原图和表格保持清晰。顶部可以暂停动效，默认遵循系统的减少动态效果偏好。警告使用琥珀底和原因文字。选中、失败、禁用均配文字；色板提供名称。异步反馈用可读状态区，重要错误留在当前任务。
键盘与焦点Tab 顺序按导航、工作区、参数、主操作推进；Esc 关闭弹窗；返回后焦点落在触发器。编辑区保留原生撤销、复制等动作。表单字段有显式标签；按钮保留可见焦点；生产验收覆盖纯键盘、中文输入法、长标题和高对比模式。

04　五个业务插件的页面设计

对话和分步页共享同一份草稿。对话提出修订时先呈现受影响的字段；用户能回到工作流查看素材、参数与预估额度。重新生成创建新任务并保留上一版，追问可引用当前结果。

插件主要操作面必须审查的交互细节
图片中间画布与图层，右侧商品素材、规格、模板、局部调整。批量 SKU 用列表展示每张结果。主图与长图可切换；结果支持分别选中主体、背景和文字。PSD 导出列明图层、授权与生成标识。单个 SKU 失败可单独重试。
视频预览播放器、分镜条、脚本编辑、音轨和比例。分镜卡承载素材、时长、运镜与提示词。换装输入含剪辑点时在提交前提示；显示自动重试次数。导出分别提供成片、抽帧和音频，检查比例与原音。
客服会话列表、聊天记录与引用资料三个区域；分步模式先选库、选场景，再提问或接管。话术可搜索插入。明确 AI 草稿和已发送状态。转人工前提示接管范围，接管后保留完整历史，关闭机器人自动回复。测试五轮追问。
运营店铺切换、授权列表、指标看板、商品批量变更及发布预览。变更表按 SKU 展示修改前后值。确认页显示平台、店铺、条数及差异。发布前必须人工确认；编辑关键字段后原确认失效。部分失败保留成功回执。
文案商品事实输入、平台与语言、可编辑正文。版本对比标出增删，违规词高亮并提供替换前后预览。按主图、详情、SKU 切换。重新生成保留历史；切到新平台重新校验长度和用语。导出取当前确认的版本。

05　状态、失败和数据边界

场景用户看到什么恢复与一致性
空项目／资料不足说明缺少的项目、素材或知识库；主按钮引导创建、导入或选择授权库。有草稿就回填。必需输入无效时保留已填值与具体原因。
失权／额度不足指出失效素材、店铺或余额。管理员与成员分别看到配置、申请额度入口。提交前服务端复验；授权失效停止执行。权限错误不暴露其他租户资料。
排队／执行／断网给出任务号、当前阶段、重试状态和更新时间。断网提示保留当前草稿。按任务 ID 恢复，断线重连先查原任务；提交使用幂等键。长任务不依赖当前页面存活。
失败／部分成功原因、涉及素材或 SKU、额度释放情况、可重试项。区分系统重试与用户重新生成。重试保留原参数并建立记录关联；批量操作仅提交失败项。待确认的店铺状态先查回执。
完成／导出结果版本、来源、生成标识、格式、保存位置与打开入口。导出失败和生成失败分开说明。默认本地保存。上传云盘需要用户主动选择；磁盘不足换目录重存，复用已有结果。
租户／项目切换显示即将切换的范围，提示未保存改动。清空旧租户缓存与订阅；草稿按租户、账户、项目和插件分区。模型请求原文及敏感凭证禁止写入前端日志。

06　前端分层与数据所有权

层级负责以图片生成为例
页面与交互页面组合、焦点、响应式与可访问性。基础组件包括导航、步骤条、结果卡、字段错误、确认框和任务表。画布和参数区订阅同一模型；用户编辑触发业务动作。
业务插件每个业务域拥有草稿、校验、授权提示、版本和工作流。页面仅通过业务动作更改状态。两种模式共用 ImageDraft，定义素材、尺寸、图层与输出格式。
公共能力会话、素材引用、任务、积分、消息与插件注册。服务端事实经查询缓存共享，临时 UI 状态保留在页面。任务模块唯一写入状态和额度结果，UI 订阅更新；重新生成关联父任务。
平台适配Web 适配浏览器文件能力；Windows 适配受限 IPC。适配器归一化错误、取消和超时语义。通过文件服务保存 PSD；Web 展示下载，桌面调用系统保存对话框。

建议前端契约：提交返回任务 ID、状态与请求标识；进度事件携带任务 ID、递增序号、阶段、错误码及可重试标记；完成结果提供文件引用、生成标识与输出版本。重连时先取快照，再接增量事件。

07　宿主与插件的前端契约

宿主保留窗口、身份验证桥、权限代理、插件注册表、诊断与恢复入口。插件以清单贡献路由、菜单、命令、工作流、设置及事件订阅。加载前校验 API 版本、权限和依赖；开发一个新插件时，通过注册表加入工作区。

动作管理页行为验收观察点
启用／停用列明使用中的命令与运行中任务；拒绝新调用，释放监听和 UI 入口。保留已保存文件，单独处理后台任务。停用图片后直接路由和命令失效，其他四项可用。重新启用恢复入口和配置。
安装／更新预览来源、版本与权限差异；新增权限需确认。新包验证失败时提示回滚结果。离线包可重装；恢复旧版本与配置后可正常打开。宿主错误与业务错误分别展示。
设备／文件插件按用途请求授权，如语音设备或保存目录。页面通过 SDK 调用，设备不可用时显示可替换项。拒绝授权后可继续浏览其他功能；同意后仅开放指定能力。终端等高权限动作由宿主复核。
卸载／崩溃卸载列出依赖方和数据保留方式。异常插件隔离，管理页提供故障原因、禁用或重装。所有可选插件关闭时，仍可进入安全模式恢复。

生产工作台与商品流转

本轮扩展为前端审查范围。商品生产、视频、数字人与声音、剪辑、经营和商品资产各有独立入口。先选任务，再填写素材、参数、分镜或商品属性，最后保存制作单。原有五个电商插件仍通过工具库进入。

路径本地可验收的行为正式对接点
商品上新创建、派生、复用、分类、编辑、导出、重新导入 JSON持久化、渲染成品、授权发布
视频、口播与混剪选择制作方式，调整镜头、时长、旁白与次序，保存制作单合成、克隆与转码服务
经营与资产单笔经济模型即时测算、编写运营及云作业草案、收藏、查看记录店铺数据、远程实例、权限及计费

工作台首页的入口与目录根据已查看的参考站整理；页面、示例和交互独立设计。制作单与档案保存在本次页面会话，可用导出功能留存。流程画板支持缩放、拖动和分支连接。账户页提供演练余额、身份权益预览及离线 ZIP。新增类目需另外评估正式开发工期。

08　审查决策与开发门槛

  1. 首页。默认先进入生产工作台；可从生产分类或侧栏自由创作进入业务页面。
  2. 导航。常驻创作台、工具库、素材库和插件管理；任务记录及企业入口独立。停用的插件不再出现在工具库。
  3. 两种模式。建议共用草稿，分步页负责可核对的结构化提交。请重点试验跨模式切换后，是否还能找到自己修改的字段。
  4. 发布确认。建议把店铺、平台、字段差异和影响 SKU 数放在最后一步，同批只确认一次。改参数必须再次确认。

审查意见可直接按“章节／页面 + 操作步骤 + 希望看到的结果”回复。完成审查后冻结导航、字段与状态，再以图片和语音插件验证 SDK；随后接入其余插件，验证 Windows 10、不同 DPI、键盘、离线和跨租户场景。
