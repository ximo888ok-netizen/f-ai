## 拉取、预览与下载

在已有仓库里执行下面两条命令，可用一个新目录查看后端分支，保留自己正在开发的工作区。新目录名可自行调整。

```sh
git fetch origin
git worktree add --detach ../f-ai-workbench-review origin/feat/backend-native-streams
```

如要查看界面，使用 Node.js 24，在新目录的 `backend` 下执行 `npm ci --include=dev`、`npm run studio:demo`，打开终端打印的本机地址。默认是 `http://127.0.0.1:8080/`，商家入口是 `/merchant`。演示模式默认使用临时数据库，生图需要工作区有可用模型和积分。CI 里的测试模型、合成素材和测试余额由用例单独创建。[启动与模型配置](../backend/README.md)

Windows x64 **后端离线包**附有归档和清单校验值。`f-ai-backend-win-x64.tar.gz` 的 SHA-256 为 `430a5eb94e1e2adc6dc2aa0c479c76cfd2787549ae68de6bade26ff0d7286a86`。用户桌面的 WebView2 安装程序有单独的构建和验收流程。[下载本次后端离线包](https://github.com/ximo888ok-netizen/f-ai/actions/runs/45622233496/artifacts/15027685583) · [Windows 桌面构建说明](../desktop/windows/README.md)
