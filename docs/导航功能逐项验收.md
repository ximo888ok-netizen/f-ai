# 导航功能逐项验收

核对日期为 2026 年 11 月 23 日。范围覆盖普通工作区的 28 个导航入口和独立商家后台的 5 个入口。每一行给出可操作的验收路径，以及应当在哪里看到结果。

依据为仓库根目录的《企业 AI 生态平台 V1 开发计划》、商家管理后台开发计划、工作台实际路由和服务端接口。运行时以当前账号、工作区、角色和能力授权为准。[V1 开发计划](../企业AI生态平台V1开发计划.docx) · [商家后台开发计划](商家管理后台开发计划.md)

## 工作区

| 序 | 导航入口 | 操作与验收要点 | 数据或运行条件 |
|---|---|---|---|
| 1 | 首页 | 输入“查商品：托特包”，用查到的商品和一张素材建草稿。也可输入“检索知识库 防尘袋”查看授权文档出处，或说“打开投放收益测算”跳到该入口。关闭对话记忆后重新进入，核对历史已清除。 | 工作区 API、当前会话和素材。模型协助单独启用并显示费用。 |
| 2 | 生产工作台 | 打开最近草稿，核对主图、任务和积分。展开“上新操作清单”，进入对应业务页并手动标记完成，刷新后查看步骤进度。 | 草稿、素材、通知、钱包、任务和成员偏好。 |
| 3 | 创作台 | 选择能力并在对话采集与工作流之间切换。填写参数，退回上一步，检查值是否保留。提交前核对参数、费用；店铺变更另核对店铺、数据和确认有效期。 | 共用能力契约、幂等提交与权限检查。本机词语检测可直接执行，外部生成取决于已配置的服务。 |
| 4 | 商品档案 | 建分类、新建商品，按名称、SKU 或分类查找，修改、复用、导出或导入。用同一 SKU 重复创建应收到冲突提示。 | 工作区商品、分类和导入导出记录。 |
| 5 | 素材库 | 上传商品图，查找后打开“文件详情”，核对来源、用途、授权期限和 SHA-256。点击“校验原文件”实际下载并重新计算摘要，再用同一素材开始图片处理。 | 原始字节和元数据，读取服从素材归属及权利限制。 |
| 6 | 任务记录 | 按状态查看任务，打开结果，按级别和时间查日志。从已结束的任务修改参数并重新提交，新结果应关联原任务，旧参数可回读。文本结果可修订、下载 TXT；有建文档权限时可另存入授权知识库。 | 当前成员任务、生命周期事件、父子任务及知识文档。 |
| 7 | 图片与视频处理 | 从素材库选图，设置画幅、尺寸、裁切或蒙版，处理后核对产物实际像素。视频可建分镜、修改镜头、提取提示词；启用媒体服务后测试截帧、音轨、重新构图和 MP4。 | 图片处理和分镜支持本机体验；视频编码依赖 FFmpeg。外部 AI 图像、视频生成另需模型。 |
| 8 | 分层设计 | 分别选择主体、背景，调整画布、位置和文字，保存后重新打开。查看 PNG 预览，下载 PSD 并核对可编辑图层。 | 分层配置、授权素材和实际 PNG、PSD 字节。 |
| 9 | 模型对话 | 选择可用模型发送消息，在成功的文字任务点击“继续这段对话”，可核对将带入的消息。语音入口选择转写、对话和合成模型并查看音频结果。 | 需要已授权模型。历史按任务归属读取，每次提交重新校验模型、积分和专家权限。 |
| 10 | 平台文案校验 | 配置各平台工作区规则，输入含“最”“第一”“100%”的标题、卖点。查看原文高亮，点击“应用词语建议并复检”。超长或禁用短语仍需人工修订；编辑原文会清除旧建议。 | 按平台和规则版本校验，替换按实际文本位置处理。 |
| 11 | 工具库 | 收藏能力并刷新。从“专家与专家团”按名称或场景检索；管理员可自建专家、关联技能、组建专家团、编辑和启停。从启用的定义带入模型对话。 | 工作区专家、关系、版本和个人收藏。执行模型对话需模型服务。 |
| 12 | 技能运行 | 打开技能，运行文案措辞检查或 SKU 核对，从结果回到商品草稿。管理员维护自定义技能；停用后运行应被拒绝。 | 实际技能定义、执行动作及版本。模型类技能另需对应模型。 |
| 13 | 拼多多草稿 | 新建草稿，选主图与规格图，填写价格、库存、多 SKU，保存后按标题查找。检查资料缺项，预览后导入库存台账。 | 本人草稿、主图授权、修订号及入账幂等检查。 |
| 14 | 拼多多运营 | 新建或打开指定台账，录入或导入订单、库存等业务记录。打开“日周月报表与导出”，选择日期及周期，下载当前查询 CSV；核对已取消订单排除、未填实付金额单列。 | 汇总来源为本台账。分组按业务日期，周一为周起点，金额使用整数分。 |
| 15 | 店铺运营 | 查看本企业已启用店铺、授权能力和登记的到期日；发布或批量修改先核对服务端预览，再确认执行。过期授权撤去可用能力，排队任务执行前再核验。 | 真实平台结果需要授权店铺及网关回执。可独立使用自有台账数据。 |
| 16 | 投放收益测算 | 输入售价、单位成本、销量、费用和广告费。核对销售额、贡献额与 ROAS，并导出包含本次输入和输出的 JSON。 | 按用户填写的实际参数计算，不预测未来成交。 |
| 17 | 客服工作台 | 选择授权知识库发起会话，检查消息顺序和引用；转人工后回复、插入快捷话术。核对新会话上下文隔离。 | 会话和引用持久化。模型回答需要已配置通道，人工流程可独立验证。 |
| 18 | 飞书消息 | 查看绑定状态，接收事件后打开对应会话，修订回复草稿并确认发送，检查送达或失败。管理员可前往商家后台检查连接。 | 真实收发需要本企业飞书应用、回调和授权。 |
| 19 | 我的项目 | 查看当前账号可见项目、状态和详情。企业管理员从页面进入商家后台，修改成员授权；普通成员重新访问时服务端检查权限。 | 工作区和项目成员关系。 |
| 20 | 知识库与记忆 | 建库、录入或上传文本，新增和改名分类；编辑文档后用新词重新检索。列出已授权成员，授予或撤销访问。个人和企业记忆分别读写。联网检索只发送用户明确输入的关键词。 | 文档、分块索引、权限与记忆。公开网页检索依赖已配置的搜索适配器。 |
| 21 | 网盘备份 | 在素材库显式选择备份，回到此页查看核验状态，下载或恢复后核对摘要。未配置时可返回素材库下载本地文件。 | WebDAV 绑定、可访问端点和真实文件；离线 HTML 无外部网盘连接。 |
| 22 | 权利通知 | 以素材提交案件，按角色转送、实施限制、处理反通知，查看案件动作与最终处置。测试受限文件的下载与解除限制。 | 权利案件、动作审计、素材访问控制。 |
| 23 | 定时任务 | 从创作表单选择未来时间，检查待执行计划，可取消或在派发后查看关联任务。重复提交相同计划不重复派发。 | 服务版由 worker 派发。本机 HTML 支持定时词语检测，工作区打开期间处理，关闭期间到期的计划在下次打开后补跑。 |
| 24 | 企业邀请 | 输入一次性邀请码，后端核验有效期、受邀邮箱和企业后刷新工作区。企业管理员可进入成员管理。 | 跨设备邀请使用已部署服务及实际受邀账号；单文件只维护隔离体验库内的邀请记录。 |
| 25 | 插件能力 | 查看每项插件的配置情况和企业开关，进入能力详情。停用后直接提交任务也要被拒绝，已有任务继续可查。 | 工作区服务策略；桌面包安装、更新与卸载属于宿主生命周期。 |
| 26 | 消息中心 | 切换全部和仅未读，按类型或时间定位通知，打开关联任务或案件，单条或全部标为已读后刷新。 | 成员通知与已读时间。 |
| 27 | 账户与积分 | 核对余额、预占、积分流水、已消费额和本人累计上限。企业管理员分配给成员后，核对两边账本。 | 工作区钱包及交易事务。真实订阅、购包支付和代理结算另行验收。 |
| 28 | 设置与诊断 | 保存任务通知、成员通知及首页对话记忆偏好。提交问题或建议，重新打开后查看反馈记录。手动检查引擎和数据库；管理员可查运行时、资源和工作区数据库状态。 | 偏好与反馈按账号和工作区保存。本机页面展示可读取的本地信息，服务端显示实际进程指标。 |

## 商家后台

| 导航入口 | 操作与验收要点 | 权限与依赖 |
|---|---|---|
| 成员与邀请 | 筛选成员，创建、重发或撤回邀请；处理成员停用和恢复。从成员行查看任务额度，设置数值后读回，留空解除限制。 | 所有者和管理员按角色分级；禁止给所有者改额度，管理员也不能改同级管理员额度。 |
| 项目管理 | 创建、改名、归档和恢复项目；授予或撤销成员访问后，从成员视角核对项目可见性。 | 仅本企业项目；成员不能访问管理入口。 |
| 功能管理 | 查看发布目录，保存启停、版本、开放范围和试用名单，返回工作台核对实际调用结果。 | 版本由部署方提供；服务端按修订号阻止旧配置覆盖新配置。 |
| 项目接入 | “读取当前接入能力”逐项读取模型、店铺、飞书、网盘、视频和搜索的工作区状态。对提供连通检查的已配置连接，可检查、断开和重新启用。 | 登记数量与远端连通性分别展示；变更由企业所有者操作。 |
| 操作记录 | 按动作、对象、日期筛选，分页查看；导出当前筛选的全部记录，核对事件、对象与操作人。 | 同时读取授权范围内的身份侧及业务侧审计数据，导出沿用相同过滤及游标。 |

## 验收范围及未完成项

- 已用隔离工作区运行服务端回归和浏览器交互。真实素材读写、文件摘要、数据库回读和导出文件内容作为验收依据。外部供应商的适配器测试使用测试端点，不代表真实商户或模型已联调。
- V1 对图片、视频生成质量、授权素材覆盖率、三平台发布回执和数据偏差均另有验收要求。需要已获授权的模型样本、真实店铺、飞书应用和网盘测试环境。此次没有执行真实扣费、上架、下架或对外发消息。
- V1 的订阅购包与支付回调、代理结算、完整 Windows 插件安装升级回滚、桌面设备及 7 日稳定性，不在本次浏览器导航验收结果中。其中尚缺的业务实现与尚待实施的部署验收均须另行完成。
