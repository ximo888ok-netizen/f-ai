# 工作台与商家后台账号验证

两端共用用户名或手机号、密码和可刷新的图形验证码。注册分为账号资料、联系方式验证两步，手机和邮箱各自验证成功后创建账号。保留黑灰白材质、个人与企业工作区，以及原有账号的业务数据。真实短信和邮件收件待部署方授权。

1. 身份与迁移。控制库新增可空的唯一用户名和手机号，允许旧记录在原账号上补绑。登录、注册和补绑在共享认证接口完成。通过用户编号、工作区和权限回读检查迁移。
2. 验证码。登录图片由服务端生成，验证后作废。注册两份短时口令分别绑定渠道、地址和同次注册，设置重发冷却与错误次数上限。账户创建和双码消费同事务完成。发送适配器使用独立的平台短信和邮件凭据。
3. 界面。登录页提供图片刷新和就地提示。注册保存上一步输入、区分两种发送状态。工作台与商家后台共享表单，窄屏优先显示输入区域。
4. 验收。在独立数据库运行过期、错误、重试、并发、唯一性和原账号补绑回归。在浏览器走双码注册、两种标识登录、商家权限和暗色窄屏。部署真实密钥之前，未配置的渠道在页面显示不可用。
