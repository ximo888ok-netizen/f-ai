## 二、实施顺序

| 批次 | 工作与依赖 | 交付物 | 完成判据 |
|---|---|---|---|
| M0　固定可复现基线 | 前端和测试先盘点当前工作树；记录 Git 基线、Node 与媒体工具版本、浏览器版本、HTML 文件摘要。将现有打包与 QA 脚本迁为仓库内可移植入口，保留当前体验库标识。 | 构建说明、可重复生成的单文件、更新后的图册、测试清单。 | 从干净临时目录仅打开一个 HTML 能使用首页、生产工作台和商家后台；覆盖已有体验库时，先前保存的商品仍可读。 |
| M1　逐入口收口 | 按第三节逐行验收。优先处理断链、保存后未落库、提交重复、更新错对象、权限越界及不可恢复的加载状态。已通过的功能建立回归记录。 | 33 行记录，每行含操作步骤、前置条件、输入、结果 ID 或文件、复测结论。 | 每个本地能力至少完成一次业务操作并回读；普通成员和无授权用户得到符合角色的结果；外部依赖入口可说明缺失的具体条件。 |
| M2　五插件业务闭环 | 依赖 M1 的能力目录、任务、素材和权限稳定。按第四节把 42 个能力逐个绑定输入表单、对话、任务、结果和交付文件。 | 能力映射表、样本索引、成功与失败记录。 | 同一能力的对话采集与工作流使用一致的参数、费用和权限；修改参数再生成保留原结果与父子关系。 |
| M3　外部服务真联调 | 部署方提供已授权测试租户、模型、店铺及回调环境。先完成配置读取、连通及权限检查，再验证实际调用和回执。可与 M2 中的本地处理工作并行。 | 每个连接的能力矩阵、到期或撤权记录、第三方回执、对账差异。 | 授权成功、过期、撤回、超时和重复回调均有对应结果。真实店铺写入具备操作人确认以及平台侧回查证据。 |
| M4　平台基础能力与桌面交付 | 产品、服务端和桌面端按第五节确认商业参数、宿主能力及部署边界。独立库和 Windows 安装需要专门环境。 | 商业流程、桌面功能和发布验证的独立任务单及测试结果。 | 订阅、代理、宿主插件生命周期、独立库切换分别验收；发布前完成 V1 规定的稳定性观察。 |

**推荐首批交付 M0 与 M1。** 可以马上开始，且最容易发现用户在当前版本中真正碰到的问题。外部服务等待授权期间，继续完成本地媒体、资料检索、权限和工件打包测试。

## 三、33 个入口的实施与复验清单

“接手重点”包含尚待开发或复核的事项。已存在的能力先复现，结果与预期一致即可登记通过。下列 `#` 后的标识可用于定位正式路由。

### 工作区快捷入口

| 入口 | 已有基础 | 接手重点与完成判据 |
|---|---|---|
| 01 首页 `#home` | 对话查商品、查任务、查询知识库、用素材加工主图并建草稿；会话按账号和工作区隔离。 | 从自然语言指令做到实际结果卡片。依次测试缺少主图、用户取消、导航中断、重试、切换企业和关闭记忆。重复保存取得同一草稿；新企业看不到旧会话。 |
| 02 生产工作台 `#desk` | 最近草稿、主图、任务、余额、未读消息、上新操作清单。 | 在其他模块改草稿、完成任务和标记通知已读，再返回核对。引导进度刷新后保留；新账号的空状态能直接开始第一项业务。 |
| 03 创作台 `#create` | 按能力契约生成参数；对话采集、工作流、参数核对、积分、店铺变更预览。 | 对五插件各选一项贯通输入、返回、修改和执行。再按 42 项展开。未配置服务仍可清楚看见输入要求；停用能力或撤销权限后，直接调用 API 同样被拦截。 |
| 04 商品档案 `#products` | 分类、商品增改、复用、导入导出、按名称或 SKU 查找。 | 测重复 SKU、空分类、导入失败再导入。由商品带入创作或草稿后核对名称、SKU 和描述；导出的文件可按约定格式重新读取。 |
| 05 素材库 `#assets` | 上传、检索、用途与授权详情、原文件下载、SHA-256 核验、链接到加工和权利通知。 | 对图片、音视频、PSD 分别抽样核对字节。检查授权到期、受限素材、被草稿引用时删除，以及失败后原文件是否完整。 |
| 06 任务记录 `#tasks` | 状态筛选、执行轨迹、按时间和级别查日志、重试、编辑原参数、父子任务、文本修订与导出。 | 验证排队取消、失败释放预占、修改后形成新任务、历史不被覆盖。另一账号不能读取原任务输入；相同幂等键只产生一次写入。 |

## 四、42 个电商能力怎样逐一收口

在能力目录旁维护逐能力清单。每行至少填写能力 ID、前端入口、输入契约、外部依赖、预览方式、执行回执、输出文件、失败样本和状态。先核对 `backend/src/catalog.js` 与正式工作台，再追到服务端执行实现。

| 插件 | V1 范围 | 关键验收 |
|---|---|---|
| 图片，共 15 项 | 商品主图、详情长图、换背景、换装、产品替换、换色、局部编辑、抠图、放大、多 SKU、延展、平台规格、在线编辑、视觉一致性、主体保真 | 抽取 3 张主图及至少 6 屏长图。检查尺寸、蒙版边界、SKU 对应、图层可编辑及来源授权。用同一组授权样本单独评估生成质量。 |
| 视频，共 12 项 | 成片、复刻、人物及产品替换、换装、图生视频、多视角、三视图、模板、分镜、画幅、音轨与导出 | 文件能力以 FFprobe、实际帧和音轨为证。生成能力按单镜头、秒数、分辨率、人物与角度范围预检，并按 V1 样本口径独立统计成功率。 |
