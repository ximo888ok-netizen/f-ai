# V1 后端验收对照 · 2026-11-22

对照仓库内《企业 AI 生态平台 V1 开发计划》。范围为后端分支在本机使用合成数据的独立部署、接口和文件验证。计划里的 81 项包括技术 8 项、平台基础 22 项、电商 42 项和交付物 9 项。下表沿用这些编号。正式放行还需要约定的候选环境、质量样本、观察周期和逐项证据。

### 本轮 P2、P3、P4 后端交付

原开发计划按功能编号分工。本轮按优先级把余下可独立验收的后端工作分为三组。

| 优先级 | 后端交付 | 验收方法 |
| --- | --- | --- |
| P2 · 插件宿主、图像导出 | SDK 提供限定服务来源的 HTTP 传输、二进制下载与错误处理。工作区管理员可为拼多多、淘宝、抖音发布版本化图片规格，批量导出可以固定规格版本 | 真实 Chromium 从获准来源上传、下载并核对摘要，从未授权来源访问时检查仅收到预检请求。三组工作区测试规格使用五张合成图，解码六张适配成品核对尺寸、主体和位置，再改变规格核对第七张裁剪结果。另测并发编辑冲突、租户隔离和旧任务重放 |
| P3 · 部署与观察 | 硬件预检按物理核心、逻辑线程、内存及所选卷的容量逐项判定。只读观察报告按版本、服务、工作区统计健康采样、连续时长和断点 | `npm run ops:capacity -- <部署目录>`，`npm run ops:observe -- report <观测库>`。短时真实采样验证探针与报告；七天合成时序覆盖中断、过期和时间不足的分支。目标部署需自行积累七天真实记录 |
| P4 · 离线交付 | Windows x64 归档列出运行时工具、原生依赖、随包许可、依赖锁文件和 Git 版本；提供独立清单摘要与核验命令 | 使用归档与清单的外部可信摘要在新目录校验，执行包内 Node、PostgreSQL、FFmpeg、FFprobe，再通过真实 HTTP 复测 SDK、模板切库、恢复和观察报告。篡改、漏项和额外原生文件另有回归 |
