# F-AI 工作台操作指南 · V1

## 商品草稿与运营台账

进入「店铺运营」，创建拼多多商品草稿，填入商品名称、分类和规格。每一行填写独立的 SKU、售价和库存，然后保存草稿。打开目标店铺的运营台账，选择从草稿导入，逐行预览。遇到重复 SKU 或缺项时先修正再预览。核对目标台账和数量后点确认。修改草稿后需取得新的预览再确认。保存草稿和确认入账都是工作区内部操作。

## 制作一套商品图

先上传有使用权的 PNG 或 JPEG 商品图。如果需要模特底图，同时登记模特图片的授权依据和有效期。套图配置保存当前成员的商品图、可选模特图、画布底色、字体、文字颜色与商品摆放区域。摆放区域的坐标和宽高按画布百分比填写。

取得配置编号和版本后，在图片批次中选择它，为各张图填写尺寸或平台规格版本及可选标题。导出时沿用同一组参照，商品放在指定区域，标题使用保存的字体。更新配置后选择新版本可生成另一套图；使用原版本可复用原版式。素材被移除、权利受限或模特授权到期时，查看失败条目并更换可用素材。

## 客服与素材

将资料加入有权限访问的知识库，在客服会话中选择对应商品，再提问并核对引用来源。同名商品按规格和商品记录区分。需要人工处理时先接管会话。下载图片或视频交付件时使用对应的导出操作，保留服务生成的标识。

## 部署自检与帮助

管理员可通过 `GET /v1/diagnostics` 查看数据库、磁盘和各目录检查项。`temporary` 和启用的 `desktop-state` 需要服务账号能创建、写入并删除文件。迁移、帮助及启用的凭证目录需要读取权限。遇到 `MISSING` 核对配置目录，遇到 `PERMISSION_DENIED` 或 `READ_ONLY` 核对服务账号权限或挂载方式，遇到 `NO_SPACE` 核对所选卷空间。修复后重新检查。

前端可读取 `GET /v1/help`，按返回的 `url` 打开本指南，并用 `sha256` 核对内容。离线部署时也可直接打开后端目录中的 `src/help/workbench-v1.md`。
